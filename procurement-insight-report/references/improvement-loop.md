# Improvement Loop

Watch for repeated procurement workflows that should be absorbed into the Skill.

## Good candidates for skill growth

- repeated weekly quote reports
- repeated chart/report formatting
- repeated endpoint conflict handling
- repeated assignee scorecards
- repeated cancellation analysis
- repeated export-to-docx workflows

## Ask the user when

- a process has repeated enough to justify codifying it
- a workaround is becoming standard practice
- the MCP has changed and new handling logic is needed

## Suggested prompt

"This looks like a repeatable procurement workflow. Do you want me to add it to the Procurement Skill so we do not have to rebuild it each time?"
