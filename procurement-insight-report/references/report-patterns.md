# Report Patterns

Prefer HTML when the user wants a visual report.

## Default report order

1. Title and reporting window
2. Executive summary
3. KPI cards
4. Charts
5. Findings
6. Insights
7. Recommended actions
8. Confidence and caveats

## Default chart choices

- Status breakdown: bar or donut
- Volume over time: line or bar
- Assignee activity: horizontal bar
- Cancellation reasons: bar
- Aging buckets: stacked bar or grouped bar

Only include charts that are clearly supported by the data retrieved.

## Audience adjustments

### Executive

- Keep it short
- Lead with totals, changes, and actions
- Use fewer charts

### Operations

- Include backlog, assignee activity, and blockers
- Emphasize aging, bottlenecks, and follow-up work

### Analyst

- Include more caveats, methodology, and supporting notes

## Export rule

Use HTML first.
Create `.docx` only when the user asks for a publishable artifact or specifies that format.
